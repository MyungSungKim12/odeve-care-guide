# 2026-11-03 시술 안내 갱신 기록

## 적용 범위

- 홈 메뉴는 눈썹, 입술, 아이라인 순서의 3개 카테고리만 제공한다.
- 각 상세 페이지는 시술 전, 시술 후, 리터치 안내의 3개 탭으로 구성한다.
- 첨부된 1~9번 JPG를 순서대로 눈썹 1~3, 아이라인 4~6, 입술 7~9에 연결한다.
- 두피와 잔흔 제거 카테고리 및 기존 미사용 이미지는 배포 대상에서 제거한다.

## 화면 기준

- 모든 일반 UI 텍스트는 브랜드 정보에 사용하던 `Noto Sans KR` 계열로 통일한다.
- `odéve` 워드마크는 브랜드 식별을 위해 기존 세리프 표현을 유지한다.
- 데스크톱 상세 화면에서 제목 아래의 불필요한 세로 여백을 줄여 탭을 위쪽에 배치한다.
- 모바일, 태블릿, 데스크톱의 기존 반응형 구조와 이미지 확대 기능은 유지한다.
- 메인 페이지 오른쪽 상단에 인스타그램 아이콘 링크를 제공하고 `odeve_beauty` 프로필을 새 탭으로 연다.
