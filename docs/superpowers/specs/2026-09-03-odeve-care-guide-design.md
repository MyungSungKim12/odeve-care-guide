# 오더브 시술 안내 웹사이트 설계

## 목적

고객이 카카오톡으로 전달받은 Vercel 링크를 열고, 원하는 시술 카테고리를 선택하여 기존 안내 이미지를 모바일에서 쉽게 확인할 수 있는 독립 프론트엔드 사이트를 만든다.

## 기술 구성

- Vite와 React를 사용하는 정적 단일 페이지 애플리케이션
- TypeScript로 카테고리와 이미지 목록을 관리
- React Router를 사용하여 카테고리별 직접 접속 URL과 브라우저 뒤로가기를 지원
- Vercel 정적 배포에 맞춘 재작성 설정 포함
- 서버, 데이터베이스, 로그인 기능은 포함하지 않음

## 화면 구조

### 홈

- `odéve` 브랜드명과 고객 안내 문구를 표시한다.
- 눈썹, 두피 SMP, 아이라인, 입술, 잔흔 제거의 다섯 카테고리를 카드로 제공한다.
- 각 카드는 간단한 영문 표기와 포함된 안내 종류를 보여준다.
- 320px 수준의 소형 스마트폰부터 대형 스마트폰, 폴더블, 태블릿, 데스크톱까지 고정 기기명이 아닌 가용 화면 너비를 기준으로 자연스럽게 재배치한다.
- 홈의 다섯 카테고리는 첫 줄 3개, 둘째 줄 2개를 가운데 정렬하여 한 화면에서 바로 선택할 수 있게 한다.
- 스마트폰과 태블릿에서는 메뉴명 중심의 간결한 버튼형 카드를 사용하고, 1024px 이상의 넓은 화면에서는 영문명과 설명을 포함한 카드로 확장한다.
- iPad와 Galaxy Tab 크기에서도 3개+2개 배열을 유지하며, 상세 화면은 읽기 좋은 최대 너비 안에서 중앙 정렬한다.
- 태블릿 가로 화면과 데스크톱에서는 탐색 영역과 이미지 영역이 지나치게 벌어지지 않도록 콘텐츠 폭을 제한한다.

### 카테고리 상세

- 카테고리명, 홈으로 돌아가기 버튼, 시술 전·후 탭을 제공한다.
- 선택한 탭에 해당하는 원본 안내 이미지를 화면 너비에 맞춰 표시한다.
- 이미지를 누르면 전체 화면에 가깝게 확대하여 볼 수 있고 닫기 버튼과 배경 클릭으로 닫을 수 있다.
- 직접 URL 접속, 새로고침, 브라우저 뒤로가기가 정상 동작한다.

### 입술 추가 콘텐츠

- 시술 전·후 안내 외에 추천 립밤, 회복 과정, 전후 참고 사진을 별도 섹션으로 표시한다.
- 세로형 회복 과정 이미지는 원본 비율을 유지한다.

## 시각 디자인

- 원본 이미지의 밝은 아이보리 질감과 회갈색 타이포그래피를 이어가는 차분하고 미니멀한 분위기
- 배경은 따뜻한 아이보리, 본문은 진한 차콜, 강조색은 뮤트 브라운을 사용
- 과한 애니메이션 없이 카드와 화면 전환에 짧고 은은한 효과만 적용
- iPhone Safari, Android Chrome, iOS·Android 카카오톡 인앱 브라우저를 우선 지원하며 최소 44px 터치 영역과 노치·홈 인디케이터 안전영역 여백을 적용
- 세로·가로 회전, 브라우저 글자 확대, 긴 화면과 짧은 화면에서도 콘텐츠가 잘리거나 겹치지 않는 유동형 레이아웃 적용
- 마우스뿐 아니라 터치 조작과 키보드 포커스 상태를 모두 지원
- CSS의 유동형 크기와 콘텐츠 기반 미디어 쿼리를 사용하여 iPad mini, iPad, iPad Pro, Galaxy Tab 계열을 포함한 중대형 화면을 지원

## 이미지 처리

- 제공된 원본 15장을 프로젝트의 정적 자산 폴더로 복사한다.
- 파일명은 의미를 알 수 있는 영문 이름으로 정리하되 이미지 자체는 편집하지 않는다.
- 브라우저가 화면에 가까운 이미지만 우선 불러오도록 지연 로딩한다.
- 안내문을 이미지 그대로 제공한다는 요구에 따라 OCR 텍스트 변환은 하지 않는다.

## 공유 및 검색 메타데이터

- 한국어 페이지 제목, 설명, 테마 색상을 설정한다.
- 카카오톡 등에서 링크 카드 생성을 돕도록 Open Graph 제목, 설명, 대표 이미지를 포함한다.
- 배포 후 공유할 주소는 반드시 `https://`로 시작하는 완전한 URL이어야 한다.
- 카카오톡 전송 시 URL을 다른 문장과 붙이지 않고 별도 줄에 배치하도록 README에 예시를 제공한다.

## 오류 및 예외 처리

- 존재하지 않는 카테고리 URL은 홈으로 돌아갈 수 있는 404 화면을 표시한다.
- 이미지 로드에 실패하면 해당 자리에 안내 메시지를 표시한다.
- JavaScript가 비활성화된 경우 기본 안내 문구를 표시한다.

- 카테고리 데이터와 URL 매핑 단위 테스트
- 홈 카드, 상세 탭, 확대 보기, 잘못된 URL 화면의 사용자 동작 테스트
